# SQL Training

Practice scripts based on the Data With Baraa SQL course, adapted to AdventureWorksDW2022.

I initially thought the course materials required payment, so I downloaded and set up a separate sample database for practice. After discovering that the materials were free, I continued using this database for consistency.

## Environment
- Database: AdventureWorksDW2022
- Local SQL Server instance: JOJO\SQL2022
- Tool: SQL Server Management Studio (SSMS)

Table and column names differ from some course examples because the scripts use this sample database.
